OrangeHRM Playwright Test Automation Framework

An end-to-end (E2E) test automation suite built with Playwright JS and Page Object Model (POM) design pattern for the OrangeHRM platform.

 Features
 Browser Coverage: Runs on Chromium with headless and headed support.
 Design Pattern: Page Object Model (POM) for clean page abstraction.
 Artifacts: Auto-captures screenshots, execution videos, and trace reports.
 Execution Options: Supports Playwright Interactive UI mode (`--ui`).
